# CASO DE USO CU-040: CONSULTAR EXPEDIENTE ACADÉMICO DIGITAL 360°

## Identificación del caso de uso

* **Código:** `CU-040`
* **Nombre:** Consultar Expediente Académico Digital 360°
* **Módulo:** Módulo 9: Perfil Académico 360°
* **Actor principal:** Aprendiz / Instructor / Administrador
* **Actores secundarios:** Base de Datos Relacional MySQL 8
* **Prioridad:** Alta
* **Estado de implementación:** 🟢 Implementado y Verificado en Rama DEV

## Descripción
Permite al aprendiz consultar su propio expediente formativo integral, y al instructor/admin auditar el progreso de cualquier aprendiz con indicadores de avance, asistencia, recuperaciones y alertas.

## Precondiciones
* Usuario autenticado en la plataforma.
* Aprendiz registrado con matrícula activa en ficha 3413988.

## Disparador
El usuario ingresa a la pestaña 'Perfil Académico 360°'.

## Flujo principal
1. El usuario selecciona la opción Perfil 360° en la barra de navegación.
2. Si es aprendiz, invoca GET /api/perfil-360/me; si es docente/admin, invoca GET /api/perfil-360/:id con selector de aprendiz.
3. El backend compila en una sola consulta estructurada los datos del usuario, inscripciones, competencias, evidencias, asistencia, recuperaciones, alertas y solicitudes.
4. Calcula en tiempo real los 6 KPIs matemáticos.
5. El frontend renderiza el banner de información general, las tarjetas métricas y las 7 pestañas temáticas.

## Flujos alternativos
* 3a. Aprendiz sin registros de asistencia: el indicador muestra 100% por defecto sin arrojar errores nulos.

## Excepciones
* 2a. Aprendiz no encontrado: código HTTP 404 con mensaje 'Aprendiz no registrado'.

## Postcondiciones
* **Éxito:** Expediente digital renderizado de forma coherente y completa.
* **Fallo:** Mensaje de error y retorno al dashboard general.

## Reglas de negocio
* RN-049: El aprendiz únicamente tiene acceso de lectura sobre su propio expediente.
* RN-050: Los porcentajes se calculan con datos vivos de la BD, prohibiendo valores estáticos simulados.

## Datos involucrados
* **Entradas:** `id_aprendiz (o token de sesión)`
* **Salidas:** `Objeto JSON multidimensional con perfil, indicadores y 7 colecciones temáticas`

## Permisos
* `APRENDIZ (propio perfil), INSTRUCTOR (fichas asignadas), ADMIN (todos).`

## Criterios de aceptación
> Cálculo preciso de porcentajes de aprobación conforme a la fórmula (aprobadas/total)*100.

## Relaciones UML
* Agregación de Competencias, Evidencias, Asistencia y Alertas.
